\# MS‑DGF‑CR

Multi‑Source Discriminative Graph Fusion CR‑score for Feature Selection



> \*\*Important note\*\*

> This repository provides skeleton interfaces and high‑level API descriptions for the proposed method.



\## Overview

This work proposes a multi‑source feature selection method based on discriminative graph fusion, including:

1\. Multi‑source explicit feature graph construction

2\. Graph auto‑encoder embedding learning for feature nodes

3\. Cross‑source consensus relation estimation

4\. CR‑score feature ranking combining discriminative and structural information
